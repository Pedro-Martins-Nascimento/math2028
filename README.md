# math2028

Repositório criado para o workspace math2028.

## Objetivo

Este repositório foi criado para organizar o desenvolvimento do projeto e manter um histórico de mudanças com Git.

## Como usar

1. Inicialize o Git no diretório local, se ainda não tiver feito:
   ```bash
   git init
   ```
2. Adicione os arquivos ao controle do Git:
   ```bash
   git add .
   ```
3. Faça o primeiro commit:
   ```bash
   git commit -m "Initial commit"
   ```
4. Conecte ao repositório remoto:
   ```bash
   git remote add origin https://github.com/Pedro-Martins-Nascimento/math2028.git
   ```
5. Envie para o GitHub:
   ```bash
   git push -u origin main
   ```
